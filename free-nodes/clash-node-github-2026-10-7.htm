三、Quantumult X 共享版的配置方法

3.1 导入 Quantumult X 共享配置

Quantumult X 支持两种方式导入共享版配置：

方法 1：使用订阅链接导入

  1. 打开 Quantumult X，进入 “配置” 界面。

  2. 选择“导入”，然后点击**“添加订阅”**。

  3. 输入你的订阅链接（通常是提供商或论坛共享的 HTTPS 网址）。

  4. 确认并保存，Quantumult X 会自动更新规则并导入所有代理节点。

方法 2：手动导入 YAML 配置文件

  1. 在 Quantumult X 里，进入**“设置” → “配置管理”**。

  2. 选择 “导入配置文件”，然后选择本地存储的 YAML 文件。

  3. 应用配置并重启 Quantumult X，新规则即可生效。

3.2 代理服务器设置

Quantumult X 需要代理服务器来工作，用户可以选择：

  • 使用公共免费代理（但可能速度慢，不稳定）；

  • 购买付费代理服务（速度快，稳定性更高）。

设置代理的方法：

  1. 进入 Quantumult X，点击 “代理” 菜单。

  2. 输入代理服务器信息（包括协议类型、服务器地址、端口号、加密方式等）。

  3. 保存并应用设置。

四、如何使用 Quantumult X 共享版？

4.1 连接并启动代理

  1. 打开 Quantumult X，进入主页。

  2. 选择一个代理服务器节点（推荐选择延迟最低的节点）。

  3. 点击“启动”按钮，Quantumult X 开始工作。

  4. 测试连接是否正常（可以打开 YouTube、Netflix 等检查是否能访问）。

4.2 配置分流规则

分流规则可以决定哪些流量走代理，哪些走本地网络，常见设置方式：

  • 全局模式（所有流量都走代理）

  • 智能分流模式（仅代理被屏蔽的网站，其余流量走直连）

  • 手动添加规则（根据自己的需求设置代理流量）

设置方法：

  1. 进入“规则”菜单。

  2. 添加规则（如让 Netflix 走代理，但 YouTube 直连）。

  3. 保存并应用规则。

FAQ

Mihomo 节点分组如何保证低延迟？
将节点按延迟、地区或用途分组，并启用策略组，系统会根据节点延迟和健康状态自动选择最佳节点。保证网页浏览、视频播放和游戏流量的低延迟和稳定连接。
VLESS + XTLS 在高延迟网络中如何优化连接？
XTLS 模式通过减少握手和加密开销降低延迟。结合策略组和多节点切换，可在高延迟或不稳定网络环境下保证网页浏览、视频播放和游戏连接稳定，提高用户体验。
V2Ray 的 mKCP 参数如何调优以适应不稳定链路？
mKCP 有多个参数如 mtu、tinterval、uplink/downlink 等，可通过降低 mtu 与增大 mtu 重试间隔来适应高丢包场景；启用 FEC 与调整窗口大小能提高容错性，最终需在实际网络环境中逐步调试获得最佳值。
为什么某些网站在通过代理后登录会频繁要求二次验证？
代理会改变访问 IP 与地理位置，目标站点可能检测到异常登录并触发验证码或二次验证。建议对常用账户使用白名单 IP 或在代理配置中对特定站点设置直连来避免频繁验证。
SSR 的混淆方式如何选择最合适？
根据网络环境选择适合的混淆方式，如 tls1.2_ticket_auth 模拟 HTTPS 流量，可隐藏真实特征。结合协议插件使用，可以提高抗封锁能力和节点可用性。
Vmess 是什么协议？
Vmess 是 V2Ray 的核心传输协议之一，提供高效的加密通信。它在客户端与服务器之间建立安全通道，支持多种传输方式，如 TCP、WebSocket 和 gRPC 等。由于其加密特性，Vmess 常用于绕过网络限制与防火墙检测。
Sing-box 如何按端口分流流量？
Sing-box 支持根据端口匹配流量，将不同应用流量分配到指定节点。结合策略组使用，可精准分流，提高访问速度和网络稳定性，优化整体网络体验。
VMess AEAD 加密在高封锁环境的优势？
AEAD 加密可防止数据篡改和流量特征泄露，降低被检测风险。在高封锁网络中，保证节点可用性和连接稳定性，同时提升数据传输安全性，确保长期安全访问。
Clash 如何通过规则文件优化流量分配？
Clash 支持自定义规则文件，可根据域名、IP 或应用类型分流流量。结合策略组使用，可自动将视频、游戏、浏览器等流量分配到最优节点，提高访问速度和网络稳定性。
Hysteria2 在丢包环境下如何配置更稳？
可调整 Hysteria2 的拥塞控制与重传参数，启用 FEC（前向纠错）并合理设置 MTU 与窗口大小以适应链路特性。还可尝试切换 QUIC 参数或更换中转以减少丢包影响。
